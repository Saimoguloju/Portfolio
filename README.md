# Moguloju Sai

Personal portfolio for Moguloju Sai, a full stack AI engineer. The site is one page: selected work, production systems, working principles, experience, and contact.

Live site: [mogulojusai.vercel.app](https://mogulojusai.vercel.app/)

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
